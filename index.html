Sentinel

Governance-risk triage for active balancer.eth Snapshot proposals.

Sentinel is a CLI application. It discovers compatible Telegraph fraud-detection Miners, sends the same assessment query for independent review, compares the returned signals, verifies x402 receipts and signal hashes, and records auditable JSONL evidence.

How it works

  1. Read an active governance proposal from Snapshot.
  2. Discover live Miners that declare the fraud-detection intent.
  3. Collect independent assessments and compare agreement.
  4. Verify receipts before recording evidence.
  5. Stop safely at 100 completed requests or the configured $1 budget.

CLI commands

npm run preflight:sentinel
npm run smoke:sentinel
npm run start:sentinel
npm run metrics:sentinel
Operational note: this page is a static showcase. Sentinel has no web UI and makes no paid request without explicit authorization and a funded wallet.
